## Resource 2: Resume/CV Job Match Score API (ApyHub)

**What it provides** (1–2 sentences):
Compares users' resumes/CVs against a chosen job description and returns a match score and analysis for hiring workflows.
**Docs link:** 
https://apyhub.com/sharpapi/service/resume-cv-job-match-score?ref=dr-pa&utm_source=public-apis-website&utm_medium=referral

**Access:** API key needed? Rate limits? Cost? (write "none" if none)
It requires an ApyHub API key; offers a free tier with limited monthly requests with 5 request/seconds. A Pro plan costs $10.40/month and a Pro+ plan costs $27.30/month.
**Sample response** (trim it to a few fields; paste the URL you called too):

URL:
https://api.apyhub.com/ai/cv-job-match/score

```json
{
    "data": {
        "match_score": 85,
        "summary": "The candidate has strong UI/UX design skills and technical project experience that highly align with the JD.",
        "missing_skills":["Vibe Coding", "LLM"]
    }
}
```

**Who could this data help, and with what?** (2–3 ideas)

1. Job seekers like Flora who want a tool that tests how well their resumes match a  job posting before submitting their applications.
2. Recruiters like Sam who want to efficiently filter out applicant resumes that doesn't match their expectations without manually reading each one. 


**One risk** (missing data, bias, privacy, or reliability):

Personal resumes usually involve sensitive personal information such as users' email address, phone number, etc. Disclosing these information to a third-party API carries privacy confidentiality risks.
