# Art Institute Search App (HCDE 310 HW4)

## Overview
This web application is designed for anyone who wants to explore the museum collection of the Art Institute of Chicago.

## How to Run
1. Open your terminal in the project directory (`hw4/`).
2. Activate the virtual environment:
   ```bash
   source .venv/bin/activate
3. Run the Flask application:
flask --app app run --debug
4. Open your browser and navigate to: http://127.0.0.1:5000
5. Enjoy!
